# 🎬 Movie Search App

## 📌 Description
A React-based web application that allows users to search for movies and view details using TMDB API.

## 🚀 Features
- 🔍 Search movies by name
- 🎥 Display movie posters
- ⭐ Show ratings and details
- ⚡ Fast and responsive UI

## 🛠️ Technologies Used
- React.js
- JavaScript
- CSS
- TMDB API

## ▶️ How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000
